# 全商英検1級 対策アプリ

2026年9月6日の全商英検1級に向けた、自分専用の学習アプリです。サーバーもログインも使わない静的サイトなので、公開してもデータが外部に送信されることはありません。学習の進み具合はすべてブラウザ内(localStorage)だけに保存されます。

## ローカルで試す

ES modules を使っているため、`index.html` を直接ダブルクリックでは動きません(ブラウザがモジュール読み込みをブロックします)。簡易サーバーを使ってください。

```
cd eiken-app
python -m http.server 8000
```

その後ブラウザで `http://localhost:8000` を開きます。

## 無料で公開する(このPCを起動していなくても使えるようにする)

GitHub Pages を使うと、GitHubアカウントさえあれば完全無料・PC不要でスマホからもいつでもアクセスできます。コマンド入力は一切不要です。

1. https://github.com/join でアカウントを作成する(無料)。
2. ログイン後、右上の「+」→「New repository」で新しいリポジトリを作成する。名前は何でもよい(例: `eiken-1kyu-app`)。Public/Privateどちらでも可(Publicの方が設定が簡単)。「Add a README file」はチェックしなくてよい。
3. 作成したリポジトリのページで「uploading an existing file」または「Add file」→「Upload files」をクリックする。
4. この `eiken-app` フォルダの**中身**(`index.html`, `css`フォルダ, `js`フォルダ)をまとめてドラッグ&ドロップでアップロードする。`eiken-app`フォルダ自体ではなく、中の`index.html`がリポジトリの一番上の階層に来るようにすること。
5. 画面下部の「Commit changes」をクリックしてアップロードを確定する。
6. リポジトリの「Settings」タブ→左メニューの「Pages」→「Build and deployment」の「Branch」を `main`(または`master`)・フォルダを `/(root)` に設定して「Save」。
7. 数分待つと、ページ上部に公開URL(`https://ユーザー名.github.io/リポジトリ名/`)が表示される。これをスマホのブラウザで開けば、このPCを起動していなくてもいつでも使える。

費用は完全に0円(GitHub Pagesは個人利用なら無料枠で十分)。

### アプリを更新したいとき

内容を修正した場合は、同じ手順で「Add file」→「Upload files」から変更したファイルを再アップロードして「Commit changes」すれば、数分で公開サイトに反映されます。

## 端末をまたぐ場合の注意

進捗データ(単語の習熟度・演習履歴など)はブラウザごとに保存されるため、PCとスマホで別々に記録されます。自動では同期しません。「設定・バックアップ」画面のエクスポート/インポート機能でJSONファイルを使って手動で移行してください。

## このアプリの前提について

- 出題形式(90分・12大問・60問・マークシート・合格ライン70点)は、全国商業高等学校協会が公開している実際の過去問(第75回, 2025年12月実施)を確認して作成しています。
- 単語帳(約250語)・演習問題(約90問)は「Batch 1」の初期セットです。今後の学習の進み具合を見ながら、追加の単語・問題セットを作ることができます。
- リスニング問題はブラウザの音声読み上げ機能(Web Speech API)を使用しています。実際の試験音声とは声質・発音が異なる点にご注意ください。
- 「合格予測(%)」はあくまで学習の進み具合から算出した目安であり、合否を保証するものではありません。
